### Challenge Design Patterns (for creating new challenges)

Effective OSINT challenges follow these patterns observed across platforms:

1. **Breadcrumb trail** — Each finding unlocks the next step (Gralhix, Bellingcat)
2. **Multi-pivot** — Start with one data point, pivot across domains (Trace Labs)
3. **Red herring resistance** — Include plausible but wrong paths (TryHackMe)
4. **Tool-agnostic** — Solvable with different tools, not locked to one (OSINT Dojo)
5. **Verifiable ground truth** — Unambiguous correct answer (all good challenges)
6. **Realistic scenario framing** — "You're a journalist investigating..." not "Find the flag"
7. **Graduated difficulty** — Easy entry point with optional hard extensions

## Evaluation Frameworks & Skill Progression

How to measure OSINT proficiency and structure skill development.

### Intelligence Cycle Mapping

Our `osint-cycle.md` reference implements the standard intelligence cycle. The broader field uses these evaluation lenses:

| Framework | Source | What It Measures |
|-----------|--------|-----------------|
| **Intelligence Cycle** | CIA/IC tradition | Process discipline: Define → Plan → Collect → Analyze → Report |
| **ACH** (Analysis of Competing Hypotheses) | Richards Heuer (CIA) | Analytical rigor: evaluating evidence against multiple hypotheses |
| **CRAAP Test** | Academic libraries | Source reliability: Currency, Relevance, Authority, Accuracy, Purpose |
| **Admiralty Code** | Military intelligence | Source + information reliability on 2-axis scale (A1-F6) |
| **Trace Labs Scoring** | Trace Labs CTF | Practical output: points for verified findings by category |
| **Bellingcat Methodology** | Bellingcat | Verification discipline: multi-source confirmation, chain of evidence |

### Skill Progression Model

**Level 1 — Single Tool (Beginner)**
- Can use one tool to answer a direct question
- Example: "Use WHOIS to find when this domain was registered"
- Our Easy challenges test this level

**Level 2 — Multi-Tool (Intermediate)**
- Chains 2-3 tools to build a fuller picture
- Example: "Use WHOIS + DNS + crt.sh to profile this domain"
- Our Medium challenges test this level

**Level 3 — Cross-Domain (Advanced)**
- Pivots across OSINT domains following leads
- Example: "Start with a username, find their real identity, locate their employer"
- Our Hard challenges test this level

**Level 4 — Creative Pivots (Expert)**
- Uses unconventional data sources and non-obvious connections
- Example: "Use flight data + property records + social media timing to establish presence"
- Our multi-domain challenges approach this level

**Level 5 — Adversarial Thinking (Master)**
- Anticipates counter-OSINT measures, works around data gaps
- Identifies disinformation, planted evidence, and deliberate obfuscation
- Example: "Determine whether this domain infrastructure was set up as a honeypot"
- Gap in our challenge suite — needs deepfake/misinfo challenges

### Common OSINT Pitfalls

| Pitfall | Description | How to Test For It |
|---------|-------------|-------------------|
| **Confirmation bias** | Seeking evidence that confirms initial hypothesis | Include challenges with misleading initial clues |
| **Single-source reliance** | Drawing conclusions from one data point | Require multi-source verification in scoring |
| **Tool fixation** | Using familiar tools when better options exist | Design challenges solvable by multiple approaches |
| **Attribution leaps** | "Same username = same person" without verification | Include challenges with common/reused usernames |
| **Temporal blindness** | Ignoring when data was collected/changed | Include challenges where timing matters |
| **Rabbit holes** | Following interesting but irrelevant leads | Time-bound challenges or efficiency scoring |
| **OPSEC failures** | Alerting the target during investigation | Note passive vs. active techniques in expected approach |

## Recommended Learning Paths

### Beginner (0-3 months)

1. **Start:** TryHackMe OhSINT room — complete intro OSINT challenge
2. **Read:** Bellingcat's "Digital Investigation Toolkit" guide
3. **Practice:** Gralhix Easy exercises (geolocation focus)
4. **Learn:** Google dorking fundamentals (TryHackMe room or our google-dorking-cheatsheet.md)
5. **Tools:** Master WHOIS, DNS lookup, EXIF extraction, username search
6. **Community:** Subscribe to Sector035 "Week in OSINT" newsletter
7. **Challenge:** Complete our Easy-rated challenges

### Intermediate (3-12 months)

1. **Course:** TCM Security OSINT course or IntelTechniques training
2. **Practice:** Bellingcat challenges, OSINT Dojo quizzes
3. **Skills:** Multi-tool chaining, cross-domain pivoting, source verification
4. **Domains:** Add infrastructure OSINT (DNS/WHOIS/certs), social media analysis
5. **Community:** Join OSINT Curious or Bellingcat Discord; participate in discussions
6. **Competition:** Trace Labs Search Party CTF (quarterly)
7. **Challenge:** Complete our Medium-rated challenges; start Hard ones

### Advanced (1+ years)

1. **Certification:** SANS GOSI or Trace Labs CTF placement
2. **Specialization:** Choose a domain (geolocation, threat intel, crypto, SOCMINT)
3. **Skills:** ACH methodology, adversarial thinking, counter-OSINT awareness
4. **Create:** Contribute challenges, write technique blogs, share tools
5. **Community:** Present at conferences (BSides, OSMOSIS, SANS Summit)
6. **Research:** Emerging areas (AI-generated content, satellite imagery, DeFi)
7. **Challenge:** Complete our Hard and multi-domain challenges; design new ones
